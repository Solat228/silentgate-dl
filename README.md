# SilentGate installer mirror

Direct, non-redirecting download URLs for SilentGate Windows installers.
They exist for the Microsoft Store, which downloads the installer from a
fixed versioned URL and does not accept redirects.

Source code, release notes and all other downloads:
https://github.com/Solat228/silentgate/releases

Files here are byte-identical copies of the GitHub release assets. A file is
never changed after it is published; a new version gets a new folder.
